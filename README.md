# Khinkali Storm

A browser-based game created using HTML, CSS and Vanilla JavaScript.

## Features

- Catch falling khinkali
- Avoid hot peppers
- Golden khinkali bonus
- Score and lives system
- Difficulty levels
- Personal best using localStorage
- Docker containers
- Node.js leaderboard microservice

## Requirements

- Docker Desktop
- Git
- GitHub

## Run the project

```bash
docker compose up -d --build
